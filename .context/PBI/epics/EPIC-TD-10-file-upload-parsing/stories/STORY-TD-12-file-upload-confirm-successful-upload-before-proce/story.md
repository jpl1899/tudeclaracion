## User story

As Rosana Ferreira, I want clear confirmation that my file uploaded successfully, so that I know processing is about to begin.

## Definition of done

- A distinct success confirmation is shown after a successful upload
- A distinct failure state is shown when the upload does not succeed
- The confirmation identifies the uploaded file (filename and upload timestamp)
